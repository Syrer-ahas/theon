# AI provider marks

- `deepseek.svg`: DeepSeek mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/deepseek.svg).
- `openai.svg`: OpenAI mark from the official [`openai/openai-agents-python`](https://github.com/openai/openai-agents-python/blob/main/docs/assets/logo.svg) repository.
- `gemini.svg`: Google Gemini mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/googlegemini.svg).
- `kimi.svg`: Kimi K mark from the [official Kimi brand guidelines](https://moonshotai.github.io/Branding-Guide/).
- `auto.svg`, `lumen.svg`, and `fortis.svg`: original interface marks created for Tactical Web. They are not third-party brand logos.

Third-party names and marks belong to their respective owners and are used only to identify the corresponding provider in the model selector.
