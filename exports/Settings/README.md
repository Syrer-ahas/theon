Performance now has three saved levels: PerformanceMode=0 Off (white, left), 1 Balanced (orange, center), 2 Maximum (green, right). Repeated clicks cycle 0 -> 1 -> 2 -> 0. The old boolean preference migrates true to Maximum and false to Off; Setting_Performance remains a derived compatibility flag. Invalid levels are rejected by the server.

Balanced keeps world textures, uses gentler animation budgets (full nearby, 30/15 Hz distant), and culls idle NPCs at 170 studs and other cars at 190. Maximum retains the stronger budget and removes world texture layers locally: Texture/Decal transparency, MeshPart/SpecialMesh texture IDs, SurfaceAppearance, clothing/effect textures, MaterialVariant, and material surface detail. Geometry, colors and UI artwork remain. All recorded values and SurfaceAppearance objects restore when switching to Balanced/Off. Newly spawned world objects are handled too.
